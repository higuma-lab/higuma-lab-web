# 素材置き場

サイトに使う素材・原稿をここに置く。箇条書きのメモで構わない。
**リポジトリは公開予定のため、公開したくない情報は置かないこと。**

## 用意するもの

- [ ] `profile.md`：経験年数、自己紹介メモ
- [ ] `services.md`：各サービスの説明メモ（対象、できること、進め方）
- [ ] `works/`：掲載する制作物ごとのメモ
  - [ ] Windowsアプリ：名称、概要、公開予定時期、ストアURL、使用技術、スクリーンショット
  - [ ] Windowsアプリのプライバシー情報：収集・保存するデータ、ネット通信の有無と送信先、利用している外部サービス（広告・解析・クラッシュレポート等）、データの削除方法
  - [ ] 本Webサイト（構築後に作成）
- [ ] `links.md`：X、Instagram、GitHub の URL
- [ ] `pricing.md`：料金の目安（決まったら）

素材がない項目は、実装時に `TODO:` 付きの仮の内容で進める。

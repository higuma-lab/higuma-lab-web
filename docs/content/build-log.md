# 構築記録

ブログ1本目「このサイトの構築記録」の材料（D-016）。各フェーズの終わりに事実を追記する。
文章として整えなくてよい。判断と理由、問題と対処、数値を残す。

## 準備（2026-10-05〜10-08）

- 最初に書いた長い依頼プロンプトを、Claude Code が読み続けるルール（`CLAUDE.md`）、要件（`docs/requirements.md`）、決定ログ（`docs/decisions.md`）に分けた。
  - 理由：1つの長いプロンプトでは、会話が長くなったときに前半のルールが抜け落ちる恐れがある。
- 実装前に決定事項を選択式で洗い出した（DNS、メール、問い合わせ方式、フレームワーク、解析、公開範囲など）。
- 「実績がこのサイトとWindowsアプリだけで公開する意味があるか」を検討 → 待たずに公開し、実績ページを「制作物・取り組み」として種別ラベル付きにする方針に（D-001）。
- AI エージェントの分担を検討 → 実装は分けず、レビュー専任のサブエージェントを3つ定義（原稿、品質、インフラ）。
  - 理由：小規模サイトでは実装を分けると統一感が崩れる。別のコンテキストで点検させる方が効果が高い。

## Phase 1〜2：現状調査・設計（2026-10-08）

- 環境：Node 24.7 / npm 11.5 / Astro 7.3 が最新安定版。
- git の `user.email` が個人アドレスだったため、公開予定のリポジトリでは GitHub の noreply に変更（D-013）。初回コミット前に気づけた。
- フレームワーク比較：Astro / Next.js（static export）/ Eleventy・Hugo → Astro。
- DNS：お名前.com の DNS ではドメイン直下を CloudFront に向けられない → ドメイン登録はお名前.com、DNS は Route 53。
- AWS 費用の見積もり：月100円前後（ほぼ Route 53 のホストゾーン代）。

## お問い合わせ

メール: [support@higuma-lab.jp](mailto:support@higuma-lab.jp)

次のことをお書き添えください。

- NoteFlip のバージョン（「…」メニュー →「**バージョン情報**」）と Windows のバージョン
- お使いの PC とペン（譜めくりの問題ならフットペダルも）
- 何をしたか、どうなるはずだったか、実際にどうなったか
- よろしければログ:「…」メニュー →「**ログのフォルダを開く**」で `noteflip.log` を添付してください。楽譜の名前は含まれません（[プライバシーポリシー](/apps/noteflip/privacy/)）。

通常、数日以内にお返事します。

## よくある質問

### 無料試用はどうなっていますか？

7 日間、すべての機能を無料でお使いいただけます。試用期間が終わると、Microsoft Store で購入するまで NoteFlip は起動しません。楽譜と書き込みは PC に残り、購入後にそのままお使いいただけます。試用中にアンインストールすると、楽譜と書き込みは削除されます。

試用やライセンスのために起動中の NoteFlip が止まることはありません。起動にインターネット接続も要りません。

### どのキーで譜めくりできますか？フットペダルは使えますか？

| 次のページ             | 前のページ                 |
| ---------------------- | -------------------------- |
| Page Down、→、↓、Space | Page Up、←、↑、Shift+Space |

キーボードとして動く Bluetooth のフットペダルは、これらのキー（たとえば Page Down と Page Up）を送るように設定すれば譜めくりに使えます。演奏中にうっかりめくらないよう、画面のタップやスワイプではめくりません。

### 取り込むと元の PDF は変更・移動されますか？

いいえ。NoteFlip は PDF のコピーを専用の保存領域に置きます。元のファイルを移動・削除してもライブラリには影響しません。書き込みも PDF とは別に保存します。

### NoteFlip をアンインストールすると楽譜はどうなりますか？

取り込んだ楽譜、書き込み、フォルダ、セットリストを含め、アプリのデータは Windows が削除します。書き込みごと残したい楽譜は、先に PDF に書き出してください（楽譜の「…」メニュー、またはライブラリの楽譜の「**PDF を書き出す...**」）。

### 書き込みごと印刷するには？

PDF に書き出し、表示されるメッセージの「**開く**」を選んで、開いた PDF アプリから印刷してください。

### 消すには？

ペンの側面ボタンを押しながら線に触れるか、ツールバーで消しゴムを選びます。「**消しゴム（全体）**」は触れた線をまるごと、「**消しゴム（部分）**」はなぞった部分だけを消します。「**元に戻す**」「**やり直し**」もツールバーにあります。

### 言語を変えるには？

「…」メニュー →「**言語**」で「**Windows の設定に従う**」「**English**」「**日本語**」から選びます。アプリを再起動すると反映されます。

### エクスプローラーから PDF を開けますか？

はい。PDF を右クリックして「**プログラムから開く**」→「**NoteFlip**」を選ぶと、ライブラリの最上位に取り込んで開きます。

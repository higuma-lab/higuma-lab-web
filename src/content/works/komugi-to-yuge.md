## 課題

Webサイト制作のプラン（5 ページまで）で、お店のサイトを毎回ゼロから作ると手間がかかります。そこで、ページの型や部品をまとめた土台（基本デザイン）を先に作り、お店ごとには色・文字・写真・文章を差し替えて作れる形を目指しました。別の業種で作った 2 件目のサンプル（架空の整体院「からだ休符」）で、使い回せるかとかかる時間を確かめました。

あわせて、小さなお店のサイトで困りやすい次の 2 つも試しました。

- お知らせやメニューを、お店の方がご自分で更新できるか
- サーバー代を抑えて公開し、お客様の名義のアカウントに引き渡せるか

## 設計

- **差し替える場所を決めておく**：店名・営業時間・メニュー・色・フォントは、設定とデータのファイルに分け、画面の部品には書かないようにしました。部品の名前も業種に寄せず、たとえばメニューの表は「料金表」として、美容室のコースや工務店の工事の料金にも使える形にしています（整体院の施術の料金表に使えることは 2 件目で確かめました。美容室・工務店はまだです）。
- **お店の方が更新するのは 3 つだけ**：お知らせ・メニュー（料金表）・営業時間は、ブラウザの管理画面から更新でき、保存すると自動でサイトに反映されます。パソコンとスマートフォンの両方で更新できることを確かめました。ページの文章や見た目は管理画面から変えられないようにして、うっかり崩れることがないようにしています。
  - 更新には GitHub（サイトのデータを保存しておくサービス）の無料のアカウントが要ります。Webサイト制作のプランでは、ご希望の方にこの仕組みを設定し、使い方をご説明します。
- **公開の費用を抑える**：サイトは Cloudflare の無料プラン（2026年10月時点）で公開し、管理画面（Sveltia CMS）も無料で使えるものを選びました（独自のドメインを使う場合は、その費用が別にかかります）。サイトのデータはお客様の GitHub に残るので、やめるときもそのまま持ち出せます。
- **引き渡しの手順を整理**：お客様の名義のアカウントで公開し、ひぐま開発室は作業者として招待していただく形の手順書を作りました。実際のお客様の案件での確認はこれからです。
- **サンプルであることを自動で表示**：全ページの「サンプル」の帯や、検索結果に出さない設定は、設定を 1 か所変えるだけで切り替わります。お客様のサイトにサンプルの内容（店名・写真・仮の住所など）が残っていると、公開の前のチェックで止まるようにしています。

## 技術

（ここからは開発者向けの内容です。）

- **サイト**：Astro 7 ＋ TypeScript（strict）。お客様が見るページには、動かすための JavaScript はありません（スマートフォンのメニューの開閉も HTML の `<details>` で作っています。管理画面を除く）。写真は AVIF・WebP に変換し、画面の幅に合わせた大きさで配信します。
- **管理画面**：Sveltia CMS。GitHub のアカウントでログインし、保存すると GitHub にコミットされ、Cloudflare が自動でビルドし直します。ログインの中継は Cloudflare Workers に置いています。
- **配信**：Cloudflare Pages。セキュリティのヘッダーと Content Security Policy は、ビルドのときに設定から書き出します。
- **テスト**：Vitest（料金や営業時間の表示、テーマの文字と背景のコントラスト比、管理画面の設定とデータの形の突き合わせ）、Playwright と axe（全ページの表示・アクセシビリティ・キーボード操作・CSP）、内部リンクのリンク切れの確認。

## 工夫した点

- **管理画面の不具合を先に見つける**：管理画面は、空の欄を「欄がない」ではなく空の値として保存することがあり、そのままではメニューを更新してもサイトに出ませんでした。お店の方の役で実際に操作して見つけ、データの読み込みと管理画面の設定の両方で直し、テストで再発を防いでいます。
- **写真は AI で生成**：写真は生成 AI で作り、実在の店や人に似せないこと、文字やロゴが写り込まないことを確かめてから使いました。サイトのフッターにも、AI で生成したイメージであることを書いています。
- **点検を分担**：実装は Claude Code で行い、原稿・サイトの品質・使い回せるかの点検は、それぞれ点検専用の AI（サブエージェント）に任せました。お店の方向けの更新の手順書と、公開・引き渡しの手順書も作っています。
- **2 件目で確かめた**：別の業種（整体院）で 2 件目のサンプルを作り、基本デザインを差し替えて使い回せることと、かかる時間を確かめました（Works の「架空の整体院『からだ休符』のサイト」）。

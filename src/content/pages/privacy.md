ひぐま開発室（HIGUMA LAB。以下「当事業者」）は、この Webサイト（higuma-lab.jp、以下「本サイト」）における個人情報とアクセス情報の取り扱いを、次のとおり定めます。

当事業者のアプリでの情報の取り扱いは、各アプリのプライバシーポリシーをご覧ください（例：[NoteFlip のプライバシーポリシー](/apps/noteflip/privacy/)）。

## お問い合わせでいただく情報

メールでお問い合わせいただいた場合、メールアドレス、お名前、お問い合わせの内容を受け取ります。これらは、お問い合わせへの回答、ご依頼に関する連絡、お見積もりや作業のためにだけ使用します。

メールの送受信には、Zoho Corporation が提供するメールサービス「Zoho Mail」を利用しています。

法令に基づく場合を除き、ご本人の同意なく第三者に提供することはありません。不要になった情報は、適切な方法で削除します。

## アクセス解析

本サイトでは、利用状況を把握してサイトを改善するために、Cloudflare, Inc. が提供する「Cloudflare Web Analytics」を使用しています。Cloudflare Web Analytics は Cookie を使用せず、閲覧したページ、参照元、ブラウザの種類などの情報を、個人を特定しない形で集計します。

収集される情報の取り扱いは、[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/ja-jp/privacypolicy/)をご覧ください。

## サイトの配信

本サイトは Amazon Web Services（AWS）を利用して配信しています。配信の仕組み上、閲覧時に IP アドレスやブラウザの情報が AWS のサーバーに送られます。

当事業者は、配信サービスのアクセスログを有効にしておらず、アクセスの記録（IP アドレスなど）を保存していません。保存するようになった場合は、目的と保存期間をこのページでお知らせします。

## 外部サイトへのリンク

本サイトには外部サイトへのリンクがあります。リンク先での情報の取り扱いは、各サイトの方針をご確認ください。

## 個人情報の開示・訂正・削除

ご本人から、当事業者が保有する個人情報の開示・訂正・削除などのご請求があった場合は、ご本人であることを確認したうえで、遅滞なく対応します。下記のお問い合わせ先までご連絡ください。

## 事業者の情報

当事業者の氏名・住所・電話番号は、お問い合わせいただければ遅滞なく回答します。

## このポリシーの変更

このポリシーは、必要に応じて変更することがあります。変更した場合は、このページでお知らせします。
